# Projects

## Photo Finder

- **Description:** Let every guest find the photos they appear in with ease using facial recognition.
- **Status:** Working
- **Tags:** Laravel, AWS Recognition, TypeScript
- **Lessons:** Importance of queued jobs. Facial recognition was is done in the background after a user uploads a photo. Improving perfomance and a great and user experience.
- **challenges:** Facial recognition was out-sourced. Intergrating it was the challenging part. It got easier once i created a model that suited my needs using an Anticorruption Layer - a pattern i recently learnt in Domain Driven Design.
- **Links:**
    - [View app](https://pick-production-ceks2g.laravel.cloud/)
